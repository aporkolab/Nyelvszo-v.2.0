Az adatbázisban található szócikkek száma a 2.2.0-ás verzióban: 12384

  1. 2.2.0 2025-08-27

    CI/CD stabilizálás és függőségfrissítések

    CI/CD

    • Javítva a backend build job: Maven helyett Node.js runtime használat.
    • npm ci futtatása a megfelelő backend munkakönyvtárban.
    • Frontend job ellenőrizve és optimalizálva: tesztek és build helyesen konfigurálva.
    • Pipeline cache stratégia bevezetve (~/.npm).

    Frontend függőségek

    • Angular: v14 → v20
    • TypeScript: ~5.8.0
    • Frissítve harmadik féltől származó csomagok:
      • ngx-bootstrap: ^9.0.0 → ^20.0.1
      • ngx-toastr: ^15.1.0 → ^19.0.0
      • zone.js: ~0.11.4 → ^0.15.0
    • Lockfile újragenerálva → függőségi konfliktusok megszüntetve.

    Eredmény

    • A CI/CD pipeline zölden fut minden környezetben.
    • A projekt függőségei naprakészek és kompatibilisek az Angular 20 ökoszisztémával.
    • Build folyamatok determinisztikusak, környezetek közötti eltérés minimális.

  2. 2.0.0 2022-10-01

    • A Heroku deploy megszűnése miatt a NyelvSzó saját szerverre került, ezzel pedig – elvileg – a végleges helyére költözött.
    • A Spring Boot-os applikáció teljes újraírásra került Angular 14-ben, TypeScript alapon. A backendet egy saját fejlesztésű Express-es alkalmazás adja.
    • NyelvSzó logó megtervezése.
    • Weblapdesign fejlesztése, frontend fejlesztése.
    • JWTWebtoken bevezetése és az adminfelület, „sózott” (hashed) jelszóval védése megtörtént.
    • A kezelőfelület és az alapvető szótári kifejezések többnyelvűsítését implementáltam.

  3. 1.3 2021-10-21

    • Teljes REST API támogatás elkészült.
    • Adminfelület kiépítése és a CRUD-műveletek frontendes megvalósítása.
    • Az adminfelület további fejlesztése megtörtént: felhasználók kezelésének kiépítését megvalósítottam.
    • Weblapdesign fejlesztése, frontend fejlesztése.
    • Spring Security bevezetése és az adminfelület jelszóval védése megtörtént.

  4. 1.0 2021-10-08

    • Az átnézett és részben javított szótári anyagot – melyet a kiadványban szereplő változat alapján fejlesztettünk tovább – JSON formátumba mentettük és H2 adatbázis készült belőle.
    • Az alapvető keresőfelület elkészült. Felhasznált technológiák: Bootstrap (HTML és CSS3), Spring Boot (Thymeleaf, Lombok).
    • A www.nyelvszo.eu domain megvásárlása.
